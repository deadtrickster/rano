# Keys audit, 2026-11-15

Asked by the operator: "I'm starting to question rano shortcuts". Written by cc@rano from the
binding tables in code at `9047198`, not from `docs/keys.md`, and from driving
`target/release/rano` in tmux. Nothing was rebound. The decisions are at the end.

Sources: `src/commands.rs:928-1187` (fifteen maps), `src/agent/keys.rs:50-139` (shared rows),
`src/keys.rs:196-262` (bottom terminal), `src/main.rs:865-867` (panel), `src/prompt.rs:116-380`
(prompts), `src/keys.rs:138-163` (completion popup).

## Findings

Ranked by how much they cost a user.

### 1. A focused terminal leaks keys into the file

`src/keys.rs:266-285` `key_bytes` translates plain characters, Enter, Backspace, arrows, Home and
End. Every other key returns `None`, `bottom_key` returns `false`, and the key goes on to the
editor's maps. Reproduced: with the shell focused, `Tab` indented line 1 of `a.rs` and marked the
buffer modified, and `C-c` ran show-location. By the same path `C-d` and `C-k` cut from the file,
`Delete` deletes in it, and `C-x` asks to quit. The shell gets no Tab completion, no `C-c`, no
`C-d`, no `C-r`, no `C-l`, no Alt chords.

### 2. The terminal's own chords take keys programs need

`src/keys.rs:219-249`: `Esc` unfocuses, so it never reaches vi, less or fzf. `PgUp`/`PgDn` scroll
rano's scrollback even when less is on screen. `M-[` (previous tab) is the CSI introducer, so it
is ambiguous with every escape sequence by timing.

### 3. Surface keys are not in any map

The terminal's `M-0`, `M-n`, `M-w`, `M-[`, `M-]` (`src/keys.rs:209-237`) and the panel's `C-]`,
`M-i`, `M-m` (`src/main.rs:865-867`) are `match` arms. `C-g k`, `C-g b`, `M-x` and the hint bar
are built from the maps, so none of them can show these keys. `M-x term` answers "no command
matches". The only place the terminal's keys are written is a literal string in the strip:
`tabs >1 (M-n new, M-[ M-] switch, M-w close)`. `docs/keys.md` has no terminal section.

### 4. Nothing can be rebound

`src/config.rs` reads `key_notation` and a key per ask preset (`:267`). There is no `[keys]`
table. Every disagreement about a chord is a code change and a release. This is the reason the
question is expensive to answer.

### 5. One chord, different meanings by surface

| Chord | Text | Elsewhere |
|---|---|---|
| `M-n` | toggle line numbers | new session (panel), new tab (terminal) |
| `M-w` | close buffer | close tab (terminal) |
| `M-]` | match bracket | next tab (terminal) |
| `M-f` / `M-b` | next / previous match | word right / left (prompt, `src/prompt.rs:256-260`), follow file (panel, `M-f`) |
| `C-c` | show location | close (views, lists), stop the turn (panel) |
| `C-g` | help prefix | cancel (prompts, views, lists, palette, folders) |
| `C-x` | quit | close (lists) |
| `Esc` | clear mark | leave the panel, leave the terminal, close anything |
| `M-p` | open preview | close preview |

`M-w` and `M-p` are the same idea on another surface and are fine. `M-n`, `M-]`, `M-f` and `C-c`
are not.

### 6. "nano's keys" is half true

README line 3 promises nano's keys. Where rano agrees: `C-x C-o C-r C-k C-u C-t C-j C-c C-/ C-\`,
`M-u M-e M-a M-6 M-] M-< M->`. Where it differs with no stated reason:

| nano | rano |
|---|---|
| `C-w` where is | unbound. Search is `C-f` (nano: forward char) |
| `C-q` where was | unbound. `C-b` (nano: back char) |
| `C-a` start of line | set mark. `C-e` is still end of line, so the pair is broken |
| `C-y` / `C-v` page up / down | `C-y` paste (shared row), `C-v` unbound |
| `M-w` / `M-q` next / previous match | `M-w` close buffer. `M-f` / `M-b` |
| `M-s` soft wrap | send position. Wrap is `M-\` (nano: top of file) |
| `M-n` line numbers | same |
| `C-l` redraw | unbound |

It is also not emacs (`C-n`/`C-p` move, `C-f`/`C-b` search) and not CUA (`C-z` undoes, `C-c`
does not copy, `C-v` does not paste, `C-s` does not save).

### 7. Duplicates for one action

Undo `M-u` and `C-z`. Redo `M-e` and `M-z`. Paste `C-u` and `C-y`. Mark `M-a` and `C-a`. Help
`C-g` and `F1`. Headings `M-t ]`/`M-}` and `M-t [`/`M-{`. Word motion `C-arrow` and `M-arrow`.
The bar shows the shared alias (`C-z Undo`, `C-y Paste`, `M-z Redo`), `docs/keys.md` lists only
the nano one (`M-u`, `M-e`, `C-u`).

### 8. Commands with only a function key

`open-file` is `F8` and nothing else (`src/commands.rs:1021`). `make-backup` is `F7`, `sort-lines`
is `F9`. A laptop keyboard or a terminal that takes the F row has no way to open a file except
`M-x`.

### 9. Chords the environment takes first

- `C-b` is tmux's default prefix. Inside tmux, where-was needs `C-b C-b`. `C-a` is screen's.
- `M-0`: GNOME Terminal switches to tab ten on Alt+0.
- `F1` (help), `F10` (menu) and `F11` (fullscreen) are taken by GNOME Terminal, and `F11` by
  most emulators.
- `M-.`, `M-,`, `M-?`, `M-|`, `M-{`, `M-}`, `M-<`, `M->` need Shift for half of them, and all
  Alt-letter chords depend on the keyboard layout. Not verified: whether an Alt chord typed in a
  Cyrillic layout reaches its binding. If it does not, every `M-` key is dead in that layout.
- `M-[` is `ESC [`. `Esc` then a fast key reads as Alt-key. The host's `Esc Esc` interrupt sits
  on the same timing.

### 10. `M-v` installs a release on one keystroke

`src/commands.rs:991`, `src/update_ctrl.rs:115-131`. No confirmation. It is one key away from
`M-b`, `M-c`, `M-n`.

### 11. `docs/keys.md` against the code

- No row for `C-z`, `M-z`, `C-y` (`src/agent/keys.rs:79-100`).
- No terminal section: `M-0`, tabs, scrollback.
- Line 168 says a plain `n` makes a session in the pick. The code is `M-n`
  (`src/commands.rs:1143`).
- `M-g` is described as opening a folder as a listing. It opens a `Directory:` prompt first.
- README line 96: "It has no GUI and no tabs". The terminal has tabs. README mentions neither
  the panel nor the terminal.

### 12. Bars truncate labels

80 columns: `C-o Write OutC-f Where Is`, `s Split/Unifi<down> Down`,
`<pgup> Page UESC Back to tM-f Follow th`. A cut label names no action. With the terminal
focused the bar still shows the editor's keys.

## Proposed keymap

One rule per layer.

Text is nano's, completed. Add `C-w` where is and `C-q` where was beside `C-f` and `C-b`. Give
`C-a` back to start-of-line and keep the mark on `M-a`. Bind `C-l` redraw. Keep `C-z`, `M-z`,
`C-y` as the shared aliases and print them in `docs/keys.md`. Give `open-file` the chord `M-o`.
Take `install-update` off `M-v` and leave it in `M-x`.

Surfaces get one family, bound in maps, the same on every surface:

| Chord | Action |
|---|---|
| `C-]` | focus the next surface: text, panel, terminal |
| `M-i` | show or hide the panel |
| `M-j` | show or hide the terminal (replaces `M-0`) |
| `M-m` | zoom the focused surface |
| `M-<` / `M->` | previous / next of what is focused: buffer, or terminal tab (replaces `M-[` `M-]`) |
| `M-w` | close what is focused: buffer, or tab |
| `M-n` in panel and terminal | new session, new tab |
| `M-PgUp` / `M-PgDn`, wheel | terminal scrollback |
| `M-+` / `M--`, drag on the rule | terminal height |

A focused terminal passes everything else to the shell, `Esc` and `PgUp`/`PgDn` included. Text
keeps `M-n` for line numbers.

Config gets `[keys]`: `"chord" = "command"` per map, applied over `Keymaps::standard()`. Then a
chord the operator dislikes is a line in a file.

Migration: old chords stay bound for one release and flash the new one. `docs/keys.md` is
regenerated from the maps, and a test fails when the two differ.

## Decisions for the operator

1. `[keys]` in the config. Recommended first, it makes 2-6 cheap.
2. Terminal toggle: `M-j`, or keep `M-0`.
3. Terminal passes `Esc` and `PgUp`/`PgDn` to the shell, with `C-]` to leave. Recommended.
4. `C-a`: start of line (nano, readline) or stays mark.
5. `C-w` / `C-q` added as nano's search keys. `C-q` is a host exit key in embedded tests
   (`src/host.rs:260`), so embedded it stays the host's.
6. `C-c` in text: keep show-location, or make it cancel everywhere. The status row already
   shows line and column.
7. `M-v` leaves the keymap.
8. `M-o` for open file.

Not decided here and not changed: findings 1, 2 and 3 are bugs and are with the rano session
(track A) at the existing chords.
